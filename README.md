# Учебная платформа

Итоговый проект по курсу «ORM-фреймворки для Java» в НИЯУ МИФИ. Предметная область охватывает организацию онлайн-курсов, запись студентов, проверку
домашних работ и тестирование знаний.

## Пользователи и профили

Сервис пользователей поддерживает создание, чтение, изменение и удаление учётных записей. Для каждой записи задаётся роль студента, преподавателя или
администратора. Адрес электронной почты приводится к нижнему регистру перед сохранением, а его уникальность обеспечивается ограничением в PostgreSQL.

Профиль хранится отдельно и связан с пользователем отношением «один к одному». В профиле доступны биография и ссылка на изображение. Профиль можно
добавить к существующей записи или удалить отдельно. При удалении пользователя его профиль удаляется автоматически.

Операции доступны через `UserService`. Сервис работает с доменными типами и интерфейсом репозитория. JPA-сущности находятся в пакете `domain.user`.
Репозиторий в пакете `repository.user` отвечает за транзакции и преобразование сущностей в объекты сервиса.

## Курсы и учебные материалы

`CourseService` предоставляет операции создания, чтения, изменения и удаления курсов, категорий, тегов, модулей и уроков. При назначении преподавателя
проверяется его роль. Каждый курс относится к одной категории и может использовать несколько общих тегов. Список курсов разбит на страницы, нумерация
начинается с нуля.

Модули входят в состав курса, уроки — в состав модуля. Порядок задаётся неотрицательным индексом, при равных индексах используется порядок
идентификаторов. Структура курса загружается явно и преобразуется в объекты сервиса внутри транзакции.

При удалении курса каскадно удаляются его модули, уроки, задания, тесты и отзывы. Категории, преподаватели и теги хранятся независимо.
Ограничения внешнего ключа защищают категории и теги, которые используются хотя бы в одном курсе.

## Запись на курс и отзывы

`EnrollmentService` записывает пользователей с ролью студента. Запись связывает студента и курс, хранит время создания и получает статус
`ACTIVE`. Запись можно перевести в статус `COMPLETED` или удалить при отписке. PostgreSQL допускает одну запись на пару «студент — курс» и
блокирует удаление курса, пока существует хотя бы одна запись. Списки студентов курса и курсов студента доступны постранично.

`CourseReviewService` позволяет создавать, читать, редактировать и удалять отзывы, а также просматривать отзывы по курсу. Автором отзыва
может быть студент. Оценка задаётся по шкале от 1 до 5, текст комментария необязателен.

## Домашние задания

`HomeworkService` связывает задание с уроком. Преподаватель курса может создавать, изменять и удалять задания, просматривать сданные работы
и выставлять оценки с комментарием. Записанный на курс студент может просматривать задания и сдавать по одному текстовому решению на каждое
задание. Работа принимается до указанного срока включительно. Срок и время сдачи хранятся как моменты времени UTC.

До проверки работа имеет статус `SUBMITTED`, после выставления балла — `GRADED`. Допустимый балл лежит в диапазоне от нуля до максимума
задания. Снизить максимум ниже уже выставленной оценки нельзя. Студент может просматривать свои работы и комментарии преподавателя.

PostgreSQL обеспечивает уникальность решения по паре «задание — студент». Сданные работы защищают от удаления задание, его урок, модуль
и курс, в том числе после отписки студента.

## Тесты и результаты

В каждом модуле может быть один тест. Преподаватель курса задаёт вопросы и варианты ответов, отмечая ровно один верный вариант в каждом
вопросе. Записанный студент получает формулировки и варианты для прохождения. Ключ ответов доступен преподавателю курса.

При прохождении студент выбирает один вариант для каждого вопроса. Вариант должен принадлежать своему вопросу. Каждый правильный ответ
даёт один балл. Для каждой попытки сохраняются время прохождения, балл и максимум на момент прохождения. Пересдачи сохраняются как
отдельные попытки. Студент видит свои результаты, преподаватель — результаты по тесту.

Наличие результатов защищает тест, его модуль и курс от удаления, в том числе после отписки студента.

## Локальный запуск

Для запуска требуются JDK 25 и созданная база PostgreSQL. Профиль `dev` активен по умолчанию. При старте Hibernate создаёт или обновляет таблицы в
существующей базе.

| Переменная    | Назначение                                                                     |
|---------------|--------------------------------------------------------------------------------|
| `DB_URL`      | JDBC-адрес базы, например `jdbc:postgresql://localhost:5432/learning_platform` |
| `DB_USERNAME` | Имя пользователя PostgreSQL                                                    |
| `DB_PASSWORD` | Пароль пользователя PostgreSQL                                                 |

Команда запуска использует эти переменные окружения.

```sh
./gradlew bootRun
```

## REST API

При запуске с профилем `dev` API доступен на `http://127.0.0.1:8080/api/v1`. Адрес привязки задаётся свойством `server.address`,
которое можно переопределить переменной окружения `SERVER_ADDRESS`.

Для локальной проверки вызывающий пользователь задаётся заголовком `X-User-Id`. Заголовок требуется при записи на курс,
создании, изменении и удалении отзывов, а также при работе с домашними заданиями и тестами. Права на эти операции определяются ролью, записью на курс
и принадлежностью работы.
Значение заголовка поступает от клиента и используется как идентификатор учебного пользователя.

| Операция                                                 | Маршрут относительно `/api/v1`                                                                    |
|----------------------------------------------------------|---------------------------------------------------------------------------------------------------|
| Список и создание пользователей                          | `GET, POST /users`                                                                                |
| Пользователь и профиль                                   | `GET, PUT, DELETE /users/{id}`                                                                    |
| Список и создание курсов                                 | `GET, POST /courses`                                                                              |
| Курс с модулями и уроками                                | `GET, PUT, DELETE /courses/{id}`                                                                  |
| Категории и теги                                         | `POST /categories`, `POST /tags`, `GET, PUT, DELETE /categories/{id}` и `/tags/{id}`              |
| Модули                                                   | `POST /courses/{courseId}/modules`, `GET, PUT, DELETE /modules/{id}`                              |
| Уроки                                                    | `POST /modules/{moduleId}/lessons`, `GET, PUT, DELETE /lessons/{id}`                              |
| Запись на курс                                           | `POST /courses/{courseId}/enrollments`, `GET, DELETE /courses/{courseId}/enrollments/{studentId}` |
| Завершение обучения                                      | `PUT /courses/{courseId}/enrollments/{studentId}/completion`                                      |
| Студенты курса и курсы студента                          | `GET /courses/{courseId}/students`, `GET /users/{studentId}/courses`                              |
| Отзывы                                                   | `GET, POST /courses/{courseId}/reviews`, `GET, PUT, DELETE /reviews/{id}`                         |
| Задания                                                  | `GET, POST /lessons/{lessonId}/assignments`, `GET, PUT, DELETE /assignments/{id}`                 |
| Сдача и список решений по заданию                        | `GET, POST /assignments/{id}/submissions`                                                         |
| Свои решения, просмотр решения и выставление оценки      | `GET /submissions`, `GET /submissions/{id}`, `PUT /submissions/{id}/grade`                        |
| Создание теста и просмотр его определения преподавателем | `POST /modules/{moduleId}/quizzes`, `GET /modules/{moduleId}/quiz/definition`                     |
| Просмотр теста студентом, изменение и удаление           | `GET /modules/{moduleId}/quiz`, `PUT, DELETE /quizzes/{id}`                                       |
| Сдача теста и результаты по тесту                        | `GET, POST /quizzes/{id}/results`                                                                 |
| Свои результаты и отдельная попытка                      | `GET /quiz-results`, `GET /quiz-results/{id}`                                                     |

У списков, которые поддерживают пагинацию, используются параметры `page` и `size`. По умолчанию возвращается первая страница размером до
20 записей. Максимальный размер страницы — 100. Список пользователей можно ограничить по роли, например `GET /users?role=STUDENT`.

Создание возвращает `201 Created` и адрес ресурса в `Location`. Чтение и обновление возвращают `200 OK`, удаление — `204 No Content`.
Ошибки возвращаются в формате `application/problem+json`. Статус `400` означает некорректный запрос, `403` — нарушение правил доступа,
`404` — отсутствие ресурса, `409` — конфликт с существующими данными или состоянием операции.

Пример создания студента в локальной базе.

```sh
curl -i http://127.0.0.1:8080/api/v1/users \
  -H 'Content-Type: application/json' \
  -d '{"name":"Аня","email":"anya@example.org","role":"STUDENT"}'
```

Для сдачи решения тело содержит `{"content":"Текст решения"}`, для оценки — `{"score":8,"feedback":"Проверить крайний случай"}`.
При прохождении теста используется тело `{"answers":{"12":34}}`, где ключ — идентификатор вопроса, а значение — идентификатор варианта.
Идентификаторы вопросов и вариантов возвращаются в представлении теста для студента.

## Проверки

Для интеграционных тестов нужен запущенный Docker. Аннотация `@WithPostgres` запускает PostgreSQL 19.0 через Testcontainers и передаёт параметры
подключения в тестовый контекст. Hibernate создаёт схему при запуске контекста.

```sh
./gradlew clean build
```
