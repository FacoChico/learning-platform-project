# Учебная платформа

Итоговый проект по курсу «ORM-фреймворки для Java» в НИЯУ МИФИ. Предметная область охватывает организацию онлайн-курсов, запись студентов, проверку
домашних работ и тестирование знаний.

## Пользователи и профили

Сервис пользователей поддерживает создание, чтение, изменение и удаление учётных записей. Для каждой записи задаётся роль студента, преподавателя или
администратора. Адрес электронной почты приводится к нижнему регистру перед сохранением, а его уникальность обеспечивается ограничением в PostgreSQL.

Профиль хранится отдельно и связан с пользователем отношением «один к одному». В профиле доступны биография и ссылка на изображение. Профиль можно
добавить к существующей записи или удалить отдельно. При удалении пользователя его профиль удаляется автоматически.

Операции доступны через `UserService`. Сервис работает с доменными типами и интерфейсом репозитория. JPA-сущности находятся в пакете `domain.user`.
Репозиторий в пакете `repository.user` отвечает за транзакции и преобразование сущностей в объекты сервиса.

## Курсы и учебные материалы

`CourseService` предоставляет операции создания, чтения, изменения и удаления курсов, категорий, тегов, модулей и уроков. При назначении преподавателя
проверяется его роль. Каждый курс относится к одной категории и может использовать несколько общих тегов. Список курсов разбит на страницы, нумерация
начинается с нуля.

Модули входят в состав курса, уроки — в состав модуля. Порядок задаётся неотрицательным индексом, при равных индексах используется порядок
идентификаторов. Структура курса загружается явно и преобразуется в объекты сервиса внутри транзакции.

Удаление курса каскадно удаляет его модули и уроки. Категории, преподаватели и теги хранятся независимо. Ограничения внешнего ключа защищают категории
и теги, которые используются хотя бы в одном курсе.

## Локальный запуск

Для запуска требуются JDK 25 и созданная база PostgreSQL. Профиль `dev` активен по умолчанию. При старте Hibernate создаёт или обновляет таблицы в
существующей базе.

| Переменная    | Назначение                                                                     |
|---------------|--------------------------------------------------------------------------------|
| `DB_URL`      | JDBC-адрес базы, например `jdbc:postgresql://localhost:5432/learning_platform` |
| `DB_USERNAME` | Имя пользователя PostgreSQL                                                    |
| `DB_PASSWORD` | Пароль пользователя PostgreSQL                                                 |

Команда запуска использует эти переменные окружения.

```sh
./gradlew bootRun
```

## Проверки

Для интеграционных тестов нужен запущенный Docker. Аннотация `@WithPostgres` запускает PostgreSQL 19.0 через Testcontainers и передаёт параметры
подключения в тестовый контекст. Hibernate создаёт схему при запуске контекста.

```sh
./gradlew clean build
```
